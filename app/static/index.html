API Tương thích OpenAI & Tích hợp Tự động hóa
Endpoint POST /v1/audio/speech tương thích trực tiếp với OpenAI TTS SDK, n8n, Open WebUI và Home Assistant — chạy hoàn toàn miễn phí trên máy bạn.
1. Ví dụ cURL (xuất MP3 + chuẩn hóa -14 LUFS)
curl -X POST http://127.0.0.1:8000/v1/audio/speech \ -H "Content-Type: application/json" \ -d '{"model":"vieneu","voice":"default","input":"Xin chào Việt Nam!","response_format":"mp3","normalize_lufs":true}' \ --output output.mp3
2. Python OpenAI SDK (dùng trực tiếp Open WebUI / script ngoài)
from openai import OpenAI client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="local") with client.audio.speech.with_streaming_response.create( model="tts-1", voice="alloy", input="Đây là giọng đọc tiếng Việt chạy local.", response_format="mp3" ) as resp: resp.stream_to_file("speech.mp3")
